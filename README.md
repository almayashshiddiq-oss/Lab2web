

## 1. Membuat Tabel (`tabel.html`)

Langkah langkah pengerjaan Tabel
1.  Membuat judul halaman menggunakan element heading
2.  Gunakan elemen `<table>` untuk membuat tabel data mahasiswa
3.  Gunakan <tr> untuk baris, <th> untuk judul kolom, dan <td> untuk isi data.
Masukkan kolom NIM, nama, dan program studi.
4.  Gunakan element `<table>`, `<thead>`, `<tbody>`, `<tfoot>`, `<caption>`, dan atribut `colspan` untuk menampilkan barisan rata-rata nilai.

## 2. Form Registrasi (`form_registrasi.html`)

1.  Buat form menggunakan elemen `<form>`
Menggunakan elemen `input` (text,Nama lengkap, email, password, date, radio, checkbox, number)  serta tombol daftar dan reset
2.  Gunakan radio button untuk pilihan jenis kelamin.
3.  Gunakan checkbox untuk pilihan keahlian seperti HTML, CSS, dan JavaScript.
4.  Tambahkan dropdown `select`untuk program studi dan `textarea` untuk alamat

## 3. Semantic HTML dan Multimedia (`multimedia.html`)
langkah langkah 
1.  Siapkan file audio dan video yang akan digunakan.
2.  Gunakan elemen <audio controls> untuk menampilkan pemutar audio.
3.  Gunakan elemen <video controls> untuk menampilkan pemutar video.
4.  Pastikan alamat file pada atribut src sesuai dengan lokasi file media.
5.  Buka halaman di browser dan uji tombol play/pause.
